# Cabbage API Hooking Lab

An educational research project exploring Windows API hooking,
DLL side-loading, and runtime instrumentation techniques.

This repository accompanies the blog post:

[Evading EDR (Part 2)](https://siabbi.ir/blog/evading-edr-for-cabbages2/)

## Overview

This project demonstrates how API interception can be used to
observe function calls and understand the mechanisms behind
EDR telemetry collection.

## Techniques Covered

- DLL Side-Loading
- Windows API Hooking
- Inline Function Patching
- Runtime Instrumentation
- Function Parameter Inspection
- x64 Calling Conventions

## Disclaimer

This project is intended strictly for educational and authorized
security research purposes. Do not deploy or use these techniques
against systems without explicit permission.
